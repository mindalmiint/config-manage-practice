Эмулятор командной строки UNIX-подобной ОС.

Описание 
Проект представляет собой эмулятор командной строки (Shell) UNIX-подобной ОС (в данном случае MAC OS), выполненный в виде графического интерфейса (GUI) на языке Python.

## Этап 1
На данном этапе реализован минимальный прототип: 
- Графический интерфейс с эмуляцией терминала REPL. 
- Формирование заголовка окна на основе данных ОС.
- Парсер аргументов (с поддержкой кавычек).
- Команды заглушки: "ls", "cd" и команда выхода "exit".

## Запуск
```bash
pip3 install pytest
make run      
make test 
```
